# nixi — Capture what moves.

A quiet little utility for keeping the internet close. The identity follows the approved nixi reference: a minimal crossed glyph with horizontal rails, a lowercase wordmark, rounded industrial panels and restrained phosphor-mint accents. Cyberpunk character comes from precise signal bars, operational labels and dark negative space.

## Themes

Preferences → Visual deck switches themes immediately and remembers the choice in this browser. Phosphor is the default. Every dark deck uses a pure-black canvas with subtly tinted panels. Daylight uses pale mineral surfaces, white panels and deep jade accents, including dialogs, form controls, tooltips and notifications.

The header glyph, SVG/PNG browser favicons and empty-state artwork change with the selected deck. Raycast uses the default Phosphor icon and Raycast’s native interface colors. Legacy Overdrive, Moonwire, Riot and Ghost preferences map to Amber, Ultraviolet, Phosphor and Infrared respectively.

## Mark and typography

Two rounded diagonals cross between short horizontal signal rails, enclosed in a rounded square tile. The mark remains readable at favicon size and has no font dependency. The standalone lowercase wordmark is drawn as vector geometry. Interface copy uses the Mac’s system sans-serif stack; small operational labels use the local monospace stack. No fonts load over the network.

## Assets

`public/icon.svg`, `public/wordmark.svg`, `public/empty-art.svg` and `public/brand-card.svg` are the default Phosphor assets. Each deck has `icon-<deck>.svg`, `favicon-32-<deck>.png`, `empty-art-<deck>.svg` and `brand-card-<deck>.svg`. Brand cards provide standalone identity artwork. The web interface renders its own live content and queue signal.

PNG favicons, an ICO, the 180px Apple touch icon, 192px/512px app icons and `manifest.webmanifest` cover browser use. `raycast/assets/nixi.png` is the 512px extension icon with its SVG source alongside it. Everything is reproducibly generated by `scripts/generate-assets.ts` using original vector geometry, mise-managed resvg and ImageMagick. No image-generation service or external artwork is needed.

## Interaction

One workspace contains the capture composer and collection. All downloads / In progress / Completed / Needs attention form a selector immediately above the table. The compact header contains the nixi identity, service availability, Downloads and Preferences. There is no page navigation or sidebar.

The queue strip reports real active and waiting jobs. Lit bars represent average progress for active downloads; idle bars stay unlit. Connecting, unavailable tools and offline states have distinct labels. Searching or filtering the collection does not change this queue-wide signal.

Paste individual or batch links, optionally preview one, then Capture links. Downloads continue independently of the page. Existing jobs keep their options and destination; clearing history preserves media. Inputs and icon actions have accessible names, visible keyboard focus and reduced-motion support. Command-Enter submits and Command-K focuses links. Controls stack on mobile and collection filters remain horizontally scrollable.

The Raycast manifest explicitly assigns the mint nixi asset to all five commands: Capture, Quick Capture, Extract Audio, Queue and Open Panel. Command names are direct actions. Batch capture and playlists remain options inside Capture, with previous downloads inside Queue.
